# TEAM Public Talks — лендинг программы вечера

Одностраничный лендинг по агенде публичной встречи TEAM University.
Чистый HTML / CSS / vanilla JS, без сборщика и зависимостей.
Три языка: русский, узбекский (латиница), английский.

## Структура

```
team-public-talks/
├── index.html          — разметка, тексты по умолчанию на русском
├── css/
│   └── styles.css      — все стили, фирменная палитра в :root
├── js/
│   ├── config.js       — ЕДИНСТВЕННЫЙ файл для правок перед деплоем
│   ├── i18n.js         — загрузка словарей, подстановка по data-i18n
│   ├── bitrix.js       — создание лида через crm.lead.add
│   └── main.js         — переключатель языка, программа, форма
├── locales/
│   ├── ru.json
│   ├── uz.json
│   └── en.json
├── assets/             — фото спикера, логотип, favicon, og-обложка
├── build.js            — сборка одного файла dist/index.html
└── README.md
```

## Локальный запуск

Словари грузятся через `fetch`, поэтому просто открыть `index.html`
двойным кликом не получится — нужен любой статический сервер:

```bash
npx serve .
# или
python3 -m http.server 8080
```

Либо собрать однофайловую версию: `node build.js` → `dist/index.html`
открывается с диска и работает без сервера.

## Что заполнить перед деплоем

Всё в `js/config.js`:

| Константа | Что вписать |
|---|---|
| `BITRIX24_WEBHOOK_URL` | Входящий вебхук портала с правом `crm`, оканчивается на `/crm.lead.add.json`. Пока пусто — форма в демо-режиме, лид не создаётся |
| `BITRIX_SOURCE_ID` | Код источника в CRM (`WEB` по умолчанию) |
| `UF_ORGANIZATION` | UF-поле «Компания или место учёбы» |
| `UF_ATTENDEE_TYPE` | UF-поле «Кто вы» |
| `UF_QUESTION` | UF-поле «Вопрос спикеру» |
| `UF_PAGE_LANGUAGE` | UF-поле «Язык страницы» |

UF-поля работают как в лендинге вступительных экзаменов: пока в константе
осталось `XXXX`, поле просто не уходит в Битрикс — остальные поля лида
создаются нормально. Вопрос спикеру дополнительно дублируется в `COMMENTS`,
так что без UF-полей ничего не теряется.

Что уходит в лид всегда: `TITLE`, `NAME` / `LAST_NAME` (имя делится по первому
пробелу), `PHONE`, `EMAIL`, `COMMENTS`, `SOURCE_ID`, `SOURCE_DESCRIPTION`
(URL страницы). Отправка — fire-and-forget: пользователь сразу видит успех,
ошибки Битрикса и ID лида пишутся в консоль с префиксом `[team-public-talks]`.

## Контент

- Тексты — в `locales/*.json`, ключи одинаковые во всех трёх файлах.
- Время и длительность блоков программы — в `AGENDA` в `js/config.js`,
  названия блоков — в словарях в `agenda.<id>`. Время не дублируется по языкам.
- Дата и время для кнопки «Добавить в календарь» — `EVENT` в `js/config.js`,
  в UTC (Ташкент = UTC+5).
- Фото спикера: положить в `assets/speaker.jpg` и заменить плейсхолдер
  в блоке `.portrait` в `index.html` на `<img src="assets/speaker.jpg" alt="Зафар Хашимов">`.

## Деплой

Статика, `vercel --prod` из корня папки. Настройки сборки не нужны —
Output Directory оставить пустым.
